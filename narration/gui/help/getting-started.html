Getting started

Requirements

  • ffmpeg and ffprobe on the PATH. Fedora's ffmpeg-free is enough; it includes libopenh264 for H.264 output.
  • wxPython from your distribution (Fedora: python3-wxpython4, plus python3-wxpython4-media for video preview).
  • PortAudio (portaudio) for audio playback.
  • A DeepInfra account and API token.

The DeepInfra token

All speech recognition, script cleanup and voice synthesis runs on DeepInfra. ReVoiceOver looks for your token in this order:

  1. the DEEPINFRA_TOKEN (or DEEPINFRA_KEY) environment variable;
  2. a .env file in the current folder or one of its parents, then ~/.config/narr/.env. Start the app with narr-gui --env-file PATH to use one specific file;
  3. the system keyring. Use Settings > DeepInfra Token… to store it there.
The token is never written to project files, config files or logs, and is masked in any message that might contain it.

Creating a project

Choose File > New Project… (Ctrl+N), or drop a video file onto the window. Then pick:

  • Video: the recording to re-voice.
  • Work folder: where every intermediate file is kept. The default is work/<video name> next to the video. Because each step saves its results there, you can stop at any time and pick up later.
  • Voice model: the text-to-speech model. Only models that support voice cloning can be used for synthesis.
  • Timing: Anchor keeps each sentence where you originally said it (best for live demos). Compact also removes dead air (best for slide narration).

To reopen a project, use File > Open Project… and choose its work folder, or pick it from Open Recent.

Your first run

  1. Press Run (Ctrl+R). Watch the Stages list and the Log tab.
  2. When the run pauses at Review script, read the Script tab. Tick Flagged only to see what needs attention first.
  3. Press Approve & Continue (Ctrl+Shift+R).
  4. Check the Quality tab and listen to flagged units.

Tip: before the first run, create a glossary of product names and acronyms. It improves both the transcript and the cleanup.
