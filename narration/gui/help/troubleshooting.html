Troubleshooting

The Log tab shows every step, warning and error. Copy diagnostics puts the whole log on the clipboard. The same log is written to run.log in the work folder.

"No DeepInfra token"

Set the token as described in Getting started. Apps started from the desktop menu don't see variables exported in your shell, so use the keyring or ~/.config/narr/.env.

"Cannot play audio"

Playback needs PortAudio and a working output device (PipeWire or PulseAudio). Install portaudio and check your sound settings.

Synthesis is slow

DeepInfra queues TTS requests; each clip can take 10–25 s. Raising [network] concurrency may help. Cancelling is safe: finished clips are cached and the next run continues from there.

A word is mispronounced or missing

Add it to pronunciations.toml, or rephrase the unit in the editor and make a New Take.

Product names are misspelled

Add them to the glossary and run from Transcribe (or at least from Clean script).

Video encoding

Re-encoding uses the first available H.264 encoder: libx264, libopenh264 (included in Fedora's ffmpeg-free), or a hardware encoder. Run ffmpeg -encoders | grep 264 to see what is installed.

A stage keeps showing "stale"

Something it depends on changed after it ran, such as an edited script or a new voice reference. Run again; only changed work is redone.
