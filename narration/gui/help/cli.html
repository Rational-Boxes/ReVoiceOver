Command line

Everything the app does is also available from the narr command, which uses the same work folders. A project started in one can be continued in the other.

narr run VIDEO                 # run until the review checkpoint
narr run VIDEO --from voice    # continue after reviewing script.json
narr run VIDEO --to transcribe # stop after a stage
narr run VIDEO --no-review     # don't pause for review
narr status VIDEO              # show each stage's status
narr gui [VIDEO]               # open the desktop app
narr token set | clear | status
narr --env-file PATH ...       # read the token from this file

The command-line work folder defaults to ./work/<video name> in the current directory; use --work-dir to choose another. To review on the command line, edit clean_text in script.json (set "edited": true to protect your change) and read script.md for the diff.
