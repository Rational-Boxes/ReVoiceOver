Project files & settings

The work folder

Every project keeps its files in one folder (by default work/<video name> next to the video). Open it with File > Show Work Folder.

project.jsonWhich video the folder belongs to
probe.json, audio_16k.wav, audio_full.wavExtracted audio
words.jsonTranscript with word timings
units.jsonNarration units
script.json, script.mdThe cleaned script, and a readable diff of it
voice.json, voice_ref.wavThe cloned voice and its reference clip
tts/, synth.jsonSynthesized clips
qa.jsonQuality-check results
cache/Cached API results, so re-runs don't cost again
run.logA log of every run
.state/What each stage last ran on (for stale detection)

You can delete the work folder to start over. The video itself is never modified.

Settings files

Settings are TOML files, layered from lowest to highest priority:

  1. ~/.config/narr/config.toml: your defaults
  2. narr.toml next to the video: shared by videos in that folder
  3. narr.toml in the work folder: this video only (the New Project dialog and the Voice tab write here)

Useful settings:

[models]
llm = "Qwen/Qwen3-235B-A22B-Instruct-2507"
tts = "Zyphra/Zonos-v0.1-hybrid"

[segment]
pause_split_s = 0.6     # a pause this long ends a unit

[clean]
batch_size = 12         # units per language-model request

[synth]
speaker_rate = 15       # Zonos speaking rate, 5-35

[qa]
max_wer = 0.15
max_retries = 3

[network]
concurrency = 6         # parallel API requests

Glossary

Put a glossary.txt next to the video with one product name, acronym or term per line (# starts a comment):

# Products
Green Canary
LEED
USGBC
WELL

The glossary primes Whisper's spelling, tells the cleanup model to write these terms exactly, and highlights them in the script editor.

Pronunciations

pronunciations.toml next to the video changes how terms are spoken without changing the script. See Quality check.
