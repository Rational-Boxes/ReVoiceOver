Pipeline stages

The Stages list on the left shows each step and its status. Every stage reads the previous stage's files and writes its own into the work folder.

Status icons

doneThe stage ran and its inputs have not changed since.
staleAn input changed after the stage ran (for example you edited the script), so it needs to run again. Stages after a stale stage are stale too.
failedThe last attempt failed; the reason is shown next to it and in the Log.
running…In progress, with a percentage where known.
waiting for youThe run paused for script review.

Running stages

  • Run (Ctrl+R) starts at the first stage that is not done and stops at the review checkpoint.
  • Run From (toolbar drop-down, or double-click a stage) re-runs from a chosen stage onward.
  • Right-click a stage for Run only.
  • Cancel (Ctrl+.) stops the job. Finished pieces are kept in the cache, so the next run continues where it stopped without paying twice.

Extract audio

Reads the video's duration and format, and writes two audio files: a 16 kHz copy for speech recognition and a 44.1 kHz copy for playback and the voice reference. Recordings longer than about ten minutes are split at silences.

Transcribe

Whisper (whisper-timestamped-medium) produces every word with its start and end time. Your glossary primes it with the right spellings. Results are cached by audio content.

Segment

Groups words into narration units: short pieces that end at a pause (over 0.6 s) or at the end of a sentence. Each unit keeps its slot, the time from its start until the next unit starts. The new narration must fit there. Very short fragments merge with their neighbour; very long ones are split.

Clean script

A language model removes fillers, stutters, repeats and false starts from each unit. Every unit comes back separately so it stays anchored to its place in the video. Suspicious results are flagged.

Review script

The checkpoint where you read and fix the script. See Reviewing the script.

Voice

Picks a clean 8–15 s stretch of your recording, uploads it once to DeepInfra and stores the returned voice id. See Voice.

Synthesize

Speaks every unit in the cloned voice (Zonos), normalizes the loudness and caches each clip by its text, so editing one sentence only re-synthesizes that sentence.

Quality check

Listens to every clip with Whisper and compares it to the script. Bad takes are retried automatically. See Quality check.

Fit timing and Assemble

Fit each clip into its slot (padding, gentle speed-up or stretching the video), then build the narration track and the final video with subtitles.

These two stages are not available in this version yet; running them reports that they are coming.
