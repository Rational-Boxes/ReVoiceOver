ReVoiceOver Help

ReVoiceOver rebuilds the narration of a screen recording. It transcribes what you said, cleans the script (fillers, stutters, false starts), lets you review it, then re-speaks it in a clone of your own voice, timed to the original video.

How a project flows

  1. Create a project from a video. See Getting started.
  2. Run the pipeline. Audio is extracted, transcribed, split into narration units and cleaned by a language model. See Pipeline stages.
  3. Review the script. The run pauses so you can read and fix the cleaned text. See Reviewing the script.
  4. Approve & Continue. Your voice is cloned, every unit is synthesized, and a quality check listens to each clip. See Voice and Quality check.
  5. Fix what QA flags, then finish the video.
